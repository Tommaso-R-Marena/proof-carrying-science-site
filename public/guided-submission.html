02

What should PCS verify?

PCS does not turn arbitrary prose directly into a trusted formal claim. It matches your project to supported claim templates, fills typed fields, and generates an exact machine-checkable predicate. You choose which rigorous meaning you intend.

YOU CONFIRM
1Your intent“Make sure train and test do not share patients.”
→
2Supported templateDataset separation by identity key
→
3Typed predicateleft dataset + right dataset + key + exact pass condition
→
4Verifier resultPCS evaluates only that exact predicate.
PCS will suggest among the formal templates it actually supports.
What can PCS formalize today?
Dataset separationNo overlap between two datasets on a declared identity key.
Reaction balanceElement counts are conserved across a declared chemical reaction.
Unit compatibilityTwo declared units reduce to the same physical dimension.
PK/PD model contractA restricted PK/PD model satisfies PCS representation, positivity, and unit rules.
PK/PD output reproductionDeclared output values match the restricted reference equations within explicit tolerances.

If your statement falls outside these templates, PCS should say not yet formalized rather than inventing semantics.

PCS did not find a currently supported formal claim automatically.

Your scientific statement may still be meaningful, but PCS does not yet have machine semantics for it. Use Advanced Mapper or the CLI to define a supported predicate; do not treat free-form prose alone as verified.
