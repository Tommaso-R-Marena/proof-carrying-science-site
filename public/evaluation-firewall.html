Reproduce the checks locally

From a checked-out PCS website source branch, use Node 22:

node scripts/semantic_evaluation_firewall.mjs pack pack.json
node scripts/semantic_evaluation_firewall.mjs baseline everything_equivalent baseline.json
node scripts/semantic_evaluation_firewall.mjs evaluate pack.json baseline.json report.json
node scripts/semantic_evaluation_firewall.mjs baseline finite_oracle oracle.json
node scripts/semantic_evaluation_firewall.mjs evaluate pack.json oracle.json oracle-report.json
node scripts/semantic_evaluation_firewall.mjs compare oracle-report.json report.json comparison.json

Evidence scope: This is public source-derived synthetic evaluation, not a blind holdout, human-derived evaluation set, unrestricted first-order theorem proving, Lean kernel evidence, or real-world AI safety verification.
