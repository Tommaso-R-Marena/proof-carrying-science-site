Restricted PK/PD model lab

Generate the computation. Then hand it to PCS for assurance.

This tool uses the same restricted one-compartment IV-bolus PK and direct Emax PD equations as the current PCS adapter. Change the parameters, generate predictions, replay them locally with the browser engine, then download a production-compatible manifest.json, pk_model.json, and predictions.csv for the Python checker.

Model parameters

This is a computational representation tool. It does not establish that a one-compartment/Emax model is empirically adequate for any drug, patient, or decision.
