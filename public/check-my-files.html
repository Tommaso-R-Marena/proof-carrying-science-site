What this result does and does not establish

This checks exact ID equality in two selected columns. A match can reveal a dataset split problem or a duplicate record, but you decide whether the overlap is appropriate. No match does not establish that a study, spreadsheet or model is correct.

The browser result is a local calculation. The desktop app independently parses the same file snapshots, checks their SHA-256 identities, encodes the selected UTF-8 IDs as strict CSV, and passes those exact derived bytes to the compiled Lean CSV checker. Lean proves the disjointness predicate for those derived lists. CSV decoding, column selection, compilation and host execution remain implementation assumptions. This is not a signed PCS scientific certificate or an immutable security boundary.

Shared reports and imported receipts are untrusted until replayed. A hash identifies bytes; it does not authenticate their author.
