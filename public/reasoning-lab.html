PCS / ASSUMPTION WORKBENCH

What must be true
for a claim to hold?

Write two logical meanings. Add the assumptions you want to rely on. Find a concrete disagreement, expose conflicting premises, or check that every allowed world agrees.

Everything runs locally in this tab. Your formulas, assumptions and world edits are never uploaded or saved. You choose the meaning of each variable; this tool checks those explicit logical choices.

01 / STATE THE MEANING

Start with an example. Then make it yours.

  1. Give each uppercase variable a meaning: for example, A means “control present” and B means “sample valid.”
  2. Write the original and candidate meanings using AND, OR, NOT and → (type ->). Parentheses group expressions.
  3. Add one assumption per line, or leave the box empty to check all possible worlds. Press “Check the reasoning.”

To test whether premises imply a claim, use TRUE as the original meaning and the claim as the candidate. AND binds more tightly than OR; implication binds last and associates to the right. TRUE and FALSE are constants. The checker accepts up to 24 variables and eight assumptions, with strict expression and computation limits.

What this establishes

The symbolic engine uses reduced ordered decision diagrams to check your declared Boolean meanings exactly, within a node and operation budget. A limit produces an unresolved result. Contradictory assumptions are reported as a conflict; they never earn an equivalence badge. A reported conflict core is inclusion-minimal: removing any one listed premise makes that core satisfiable. It may not be the smallest possible core.

This is an experimental Boolean reasoning tool. It does not understand papers automatically, verify your variable meanings against experiments, train a new language model, or run a Lean kernel in the browser. The existing trained repair models remain available in the model workspace within their published four-variable scope.

Downloads include the exact formal task, work limits, decision diagram, witnesses and content hashes. Hashes identify content; they do not authenticate scientific authority. Reproduce the result with the independent public Python implementation:

pcs conditional verify pcs-conditional-result.json
pcs conditional check task.json --output NEW_RESULT.json
