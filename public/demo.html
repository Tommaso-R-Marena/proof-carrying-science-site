Legacy v0.5 parity engine

Inspect the older reference package transparently.

This browser engine remains a useful v0.5 parity fixture: it verifies the frozen reference package or an extracted v0.5 evidence directory, hashes staged bytes, checks the package signature, replays the restricted PK/PD checks, reassesses claims, and applies policy. The current v0.6 MVP uses the Python CLI for deterministic bundle creation, extraction-free ZIP verification, normalized-decision regeneration, and SHA-bound reviewer policy.
