Local setup and supported language

From a PCS checkout with Python 3.12 and Lean 4.28 activated:

source scripts/activate_lean_428.sh
python -m pip install --require-hashes \
  -r requirements-build.lock -r requirements-dev.lock -r requirements-prover.lock
python -m pip install --no-deps --no-build-isolation -e .
python -m pcs.experimental.prover.server \
  --models research/lean-learning-v2 \
  --reuse-models research/checked-reuse-v2 \
  --abstraction-models research/induction-abstraction-v2 \
  --public ../proof-carrying-science-site/public

Open the local lab. No model API key, paid GPU or Cloudflare change is required.

Supported: explicit propositions, natural numbers, integers; equality and ≤ over numbers; lists of natural numbers, append, length, reversal and successor; arithmetic; and/or/not/implication; typed quantification, Nat→Nat injectivity/composition and Nat→Prop predicates. Mixed and/or groupings require your selection. Real numbers, graphs, unrestricted definitions and arbitrary Lean source remain unsupported.

A goal is something still to prove. A local assumption is something you may use. Splitting a conjunction creates two goals; both must close. Introductions use names h0, h1, …; their types show whether they are variables or assumptions.
