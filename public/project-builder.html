How confirmation works
Safety boundary: this mapper recommends structure; it does not decide scientific truth. The exported draft is intentionally non-attestable until you run pcs confirm-v06, which re-hashes the selected artifacts locally before permitting attestation.

Continue in the CLI

If the browser downloaded the draft outside the project directory, point confirmation at the original project root:

pcs confirm-v06 ~/Downloads/pcs-manifest.draft.json --project-root ./my-project -o ./my-project/manifest.json
pcs attest-v06 ./my-project/manifest.json -o study.pcs.zip --private-key organization-private.pem --public-key organization-public.pem
