What unlocks what—and exactly why?

A dependency edge in PCS should identify the required upstream output, the semantic relationship, and the gate logic. “A depends on B” is not enough. Groups can require all inputs, any one input, or at least k accepted inputs before downstream work unlocks.

Edge semantics

Every edge should say what travels across it.

A relation such as test_oracle, specification, independent_review_gate, or informs is paired with an artifact contract describing the accepted output the downstream node consumes.

Unlock logic

Prerequisites are logical gates.

PCS supports grouped gates such as ALL, ANY, and AT_LEAST(k). Informative edges can shape work without blocking it. This keeps sequencing explicit while still allowing safe parallel work.
