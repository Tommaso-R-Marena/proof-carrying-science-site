What the guarantee covers

The native checker decodes the original CSV bytes using a proved byte grammar for PCS’s bounded UTF-8 CSV dialect. Its preservation theorem covers exact IDs and selected values, including quoted fields and embedded LF/CRLF. If new records are allowed and removal/editing is forbidden, every previous selected record must remain present unchanged.

File-to-process binding, compilation and host execution remain assumptions. Selecting the right ID and comparison columns is your responsibility. This does not establish scientific validity, authenticate a publisher or issue a signed PCS certificate. Imported receipts need fresh replay.
