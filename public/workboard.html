What each stage guarantees

Task accepted: assignment approved for the required level and time window, not a claim of work quality. Submitted: evidence saved, not necessarily verified. PCS/CI: a named checker completed on pinned bytes; it may be only an artifact/contract check. Reviewed: an authorized human made an explicit decision. Archived: the submission PR merged to the contribution evidence area, not the production kernel. Production: a separately reviewed, pinned promotion PR merged after fresh checks and owner approval.

Only the Founder/Owner can authorize production merges. L5/L6 expertise supports independent technical reviews; no automatic CI run can replace responsible human signoff.
