# Bundled web fonts

These five WOFF2 fonts arrived in website PR #120. Their original bytes and embedded copyright notices are recorded in `licenses/FONT_IDENTITIES.json`. The IBM Plex, Source Sans and Source Serif SIL Open Font License texts accompany the font files. Each upstream text has its fetched URL, Git blob and SHA-256 recorded beside it. No font binaries were modified.

The font metadata identifies IBM and Adobe families and links to the OFL. This audit does not establish that each subset is byte-identical to a particular upstream release. Keep that provenance limitation separate from the broader licensing review in PCS issue #11.
