    Inspect model provenance and verification limits

    Model format: pcs-learned-semantic-repair-policy-v1. A deterministic 384-dimensional hashed feature ranker trained using pairwise logistic loss on finite-model checker labels, with a pinned source digest and fixed random seed.

    What counts as verified: one candidate agrees with the source in every world enumerated by the fixed game evaluator, within the displayed finite domain bound. An independent result is computed for each attempted edit. A high model score alone never counts as success.

    Not proved: equivalence in all structures, faithful English interpretation, Lean compilation, scientific truth, human gameplay provenance, or AI alignment. The public source and evaluation cases can be inspected; this is not a secret or independently blind benchmark.
