# Guarded recovery: actual model continuations and formal model

All records are unsigned synthetic research evidence. No participant data or training permission is implied. The [report](../../docs/GUARDED_RECOVERY.md) explains findings, assumptions, exact theorems and reproduction.

- `state-only/`: 48 actual Qwen3-0.6B Q8_0 requests. Twelve denied delivery/gate proposals recovered; twelve maintenance tasks exhausted budgets. The complete negative result is retained.
- `history/`: 24 actual requests on the same 36 archived initial conditions. Exact recorded user/action/obligation history was added under a clean repair system prompt; the original compromised system prompt was excluded. All 36 seeded tasks completed with no unauthorized effects. Twelve needed no new call because their seed already completed the benign task.
- `*-independent.json`: Python replay of the real TypeScript receipt decisions, histories, raw responses and states. This is not an independent rerun of inference.
- `*-source.tar.gz`: exact source snapshots recorded before the respective first model call. Current-code replay confirms compatibility with both versions.
- `lean-axioms.log`: thirteen compiled Lean 4.28.0 theorem audits. Only standard `propext` appears, except the axiom-free completion bound.
- `lean-differential.json`: 92,823 exact bounded implementation comparisons, source digest and table digest. The theorem is universal over its mathematical action vocabulary; this implementation test is bounded.
- `baseline.log`: independently rerun 125-test/6-test baseline and the prior 172-transition replay before the new implementation.
- `verification.log`: final type/lint/format/build checks, 132 TypeScript tests, twelve Python tests and both phases' current-code replays. Readable console copies trim trailing whitespace only; `raw-console.tar.gz` preserves their original bytes, including runtime and axiom logs.

The two new studies use **72 actual inference requests**. The 36 initial model proposals are reused from the preserved `model-safety-v1` fault experiment; replaying them is not new model inference. Total actual requests across both phases: **194**. Every effect is in fresh synthetic memory. No hosted API, new compute resource, production deployment or production authority change is involved.

State-only raw `failed` counters count transport/parsing/submission errors, not all incomplete tasks. Read the per-episode `budget_exhausted` statuses and completion totals. A legal completion exists in the Lean model; the small model's ability to discover it is an empirical question. Do not conflate those guarantees.
