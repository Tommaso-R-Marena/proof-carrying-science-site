# Review checklist

This is a draft playtest candidate, not a production release or published study.

- [x] Isolated feature worktree based on exact protected site main; no existing PCS source or workflow edited.
- [x] Three distinct missions and four functioning gadgets, guard/courier/technician behavior, collision, goals, scoring, result/retry, local scores/settings/history/cosmetics.
- [x] Actual valid-input browser mission completions, desktop and narrow layout evidence.
- [x] Optional local capture and lab, three schema-validated synthetic mappings, control/attack fixtures, independent guarded final-state grading and hashed reports.
- [x] Server-only explicit-opt-in bounded model adapter; mocks labeled synthetic; no evaluation endpoint in browser/status service.
- [x] Typecheck, lint, formatting, unit/integration, production build, Chromium/Firefox, production-isolation checks and soak performed; exact results in TEST_REPORT.
- [x] Browser test controller absent in production. No server credentials or real model calls in normal verification.
- [x] Original art/synthesis, license notices, method/threat/privacy/reproducibility documentation.
- [x] New CI is read-only and has no merge/deployment steps, API keys, or model calls.
- [ ] Owner reviews PR, game balance and screenshots.
- [ ] Consenting novice playtest; fun and real-device performance remain unmeasured.
- [ ] Any future live-model evaluation receives separate deliberate operator opt-in and an appropriate model/budget.
- [ ] Separate authorization before merge, public playtest deployment, repository creation, or human data collection.

Normal browser/fixture gates can be completed without credentials. Human enjoyment, model behavior on real providers and external validity are not substituted by automated pass counts.
