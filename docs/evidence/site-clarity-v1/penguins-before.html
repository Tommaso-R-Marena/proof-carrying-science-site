From an updated PCS core checkout with its documented dependencies and compiled authority installed, place the downloaded bundle and public key in your current directory, then run:

python scripts/run_scientific_workflow_v2.py \
  --replay positive.pcs.zip --public-key producer-public.pem \
  --fingerprint f7e1184ae513ef6fe9688094fa0d64e2d94bb4f9752d3f7c35a2b44b009146e5 \
  --output /tmp/pcs-scientific-fresh-receiver.json

The output path must be new. This is a real receiving command, not a browser checker. Pin the producer fingerprint through a source you trust; the website's unsigned hash inventory alone does not authenticate scientific claims. A new independent replay is required to establish your local result.
