# Omega research workspace v1

`/omega-workspace.html` is a local-first visual interface to PCS Omega's explicit Boolean reasoning experiment. It accepts source-bound project JSON (64 KiB), checks exact claim ranges and dependency cycles, and displays clickable source, claim, equivalence, grounding and authority nodes. Source and edits stay in browser memory. The page sends no user project, actions or research donation to a server and persists nothing across reloads. Public assets and checkpoint downloads still use normal infrastructure request handling.

The independent JavaScript checker evaluates all Boolean valuations for 1–4 symbols. Repair actions are bounded typed AST edits; the selected source interpretation cannot change during search. Every transition and receipt is replayed before export. Edits invalidate the graph and disable stale evidence downloads. Model files never execute code or approve authority. Dynamic source, claim and model metadata are rendered using text nodes.

The three actual CPU-trained checkpoints are pinned by canonical digest in the controller. They share the core's 38-dimensional bag features or 91-dimensional fixed two-round AST graph features. Training is weighted logistic SGD or one-step REINFORCE, never a model API call. Graph encoding is fixed, not an end-to-end GNN. The website retains the actual measured report, full per-task outcomes and actual Lean axiom inventory. At eight checker calls the bag model solved 73/96 public family-held-out tasks versus structural search's 68/96; graph 66/96 and bandit 65/96. At four calls all learned heads lost. Structural search remains the default. Public generated single-seed tasks establish neither broad scientific transfer nor statistical superiority.

The graph is explicitly a local project view. Download the project and run `pcs omega intake` for the existing canonical Claim IR / Proof Obligation Graph. Downloaded search episodes replay unchanged with `pcs omega replay`. The checked task replays with `pcs omega check`. Lean downloads are exact fixed templates for the repaired interpretation; users must compile them with Lean 4.28. No browser Lean execution or signed scientific receipt is claimed. Grounding and registered authority remain open after logical repair.

Required CI checks 192 tasks against the independent pinned Python core, 1,146 feature vectors and 120 exact bounded search episodes across deterministic and actual learned strategies. The real-browser gate checks desktop/mobile graph and search flows, complete strategy comparison, trajectory and proof downloads, unsupported-input rejection and stale-evidence invalidation, alongside existing account/authority and research donation/deletion controls. Synthetic browser fixtures are isolated to loopback Worker/D1; production verification uses only reads and local calculations.

No new D1 migration, arbitrary code sandbox, participant-data training or paid service is introduced. Existing Countermodel Lab and Safety Forge provide the separate consent-based real-game research pipeline. Future corpus collection, general natural-language interpretation, larger trained graph models and long-horizon RL remain research milestones, not features claimed by this workspace.
